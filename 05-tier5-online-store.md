# Tier 5: The Online Store

## The chain

Customer → Application (the store's website or app) → Instructions (the program's code) → Data processing → Stored data (database) → Result

## Answers

- **What is the computer doing?** Running the program: carrying out instructions, doing the calculations, and storing and fetching data.
- **What is the program doing?** Receiving the order, checking stock, calculating the total, saving the order, and sending back a confirmation.
- **What data is involved?** Product name, price, quantity, customer name, delivery address, and payment details.
- **What instructions are executed?** Find the product. Check it's in stock. Multiply price by quantity. Process payment. Save the order. Reduce the stock count.
- **What is the output?** A confirmation like "Order confirmed. Total: 100,000."
- **What needs to be stored?** The customer, product, quantity, total, order status, and delivery details, so the system remembers the order later.
